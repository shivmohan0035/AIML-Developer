# Pandas  ---> Pandas is fast,powerful, flexible, open source python library which is used for data analysis and manipulation. 
# Two main data structures in pandas are Series and DataFrame.

# Series ---> Series is a one-dimensional labeled array capable of holding any data type (integers, strings, floating point numbers, Python objects, etc.). The axis labels are collectively referred to as the index.

# DataFrame ---> DataFrame is a two-dimensional labeled data structure with columns of potentially different types. It is similar to a spreadsheet or SQL table, or a dict of Series objects.
